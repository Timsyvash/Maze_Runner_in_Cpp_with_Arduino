# 🎮 Maze Runner in C++ with Arduino

Інтерактивна гра-лабіринт на базі мікроконтролера Arduino, адресної світлодіодної матриці WS2812B (8x8) та аналогового джойстика. Гравець керує білою точкою, пересуваючись лабіринтом із червоними стінами до зеленого фінішу.

У проєкті реалізовано алгоритми обробки аналогового шуму АЦП, захист від діагонального «прольоту» крізь стіни та підтримку різних типів розводки плати.

---

## 🚀 Основні можливості

* **Динамічна карта лабіринту:** Відображення стін (червоний), фінішу (зелений) та гравця (білий).
* **Захист від колізій (Collision Detection):** Гравець фізично не може зайти на клітинки зі стінами.
* **Алгоритм точності ходу:** Фіксація лише домінуючої осі руху запобігає випадковим діагональним стрибкам та «телепортації» під час ковзання вздовж стін.
* **Стабілізація АЦП:** Подвійне зчитування аналогових пінів з мікрозатримкою ($10\,\mu\text{s}$) усуває наводки між вісями джойстика.
* **Підтримка геометрії матриць:** Можливість швидкого вибору одного з 4 типів розводки світлодіодів (`MATRIX_TYPE`).

---

## 🛠️ Необхідні компоненти

1. **Мікроконтролер:** Arduino (Uno / Nano / Pro Mini)
2. **Дисплей:** Світлодіодна матриця **WS2812B 8x8** (64 RGB LED)
3. **Керування:** Аналоговий 2-осьовий джойстик (модуль HW-504 / KY-023)
4. **Живлення:** 5V (USB або зовнішнє джерело живлення)
5. Макетна плата та з'єднувальні дроти

---

## 🔌 Схема підключення

| Компонент | Пін компонента | Пін Arduino | Примітка |
| :--- | :--- | :--- | :--- |
| **Матриця WS2812B** | **DIN** | `D6` | Вхід даних (Data In) |
| | **5V / VCC** | `5V` | Живлення |
| | **GND** | `GND` | Спільна земля |
| **Аналоговий джойстик** | **VRx** | `A4` | Вісь X |
| | **VRy** | `A3` | Вісь Y |
| | **+5V / VCC** | `5V` | Живлення |
| | **GND** | `GND` | Спільна земля |

> ⚠️ **Зверніть увагу:** Підключайте сигнал даних саме до контакту **DIN** (а не DOUT) матриці.

## 📚 Залежності

Для роботи проєкту необхідна бібліотека **Adafruit NeoPixel**.  
Установити її можна через менеджер бібліотек Arduino IDE:
1. Перейдіть у `Tools` $\rightarrow$ `Manage Libraries...`
2. Знайдіть **Adafruit NeoPixel**
3. Натисніть **Install**

## ⚙️ Налаштування геометрії матриці

Оскільки світлодіодні матриці 8x8 мають різні схеми з'єднання світлодіодів, параметр `MATRIX_TYPE` дозволяє вибрати правильну топологію:

* `1` — Горизонтальна пряма (Progressive)
* `2` — Горизонтальна змійка (Serpentine) — *значення за замовчуванням*
* `3` — Вертикальна пряма
* `4` — Вертикальна змійка
